# 📊 Sales Prediction ML

An end-to-end Machine Learning project that predicts supermarket sales using customer, product, transaction, and business-related features.

This project covers the complete Machine Learning workflow, from Exploratory Data Analysis and data preprocessing to model training, evaluation, FastAPI deployment, and frontend integration.

---

## 🎯 Project Objective

The objective of this project is to build a Machine Learning system that can predict expected sales based on different transaction and customer-related features.

The system can be useful for:

- Sales prediction
- Revenue planning
- Business analysis
- Understanding sales patterns
- Data-driven decision making
